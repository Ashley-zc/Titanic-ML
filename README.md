# Titanic 幸存者预测 - 完整机器学习项目

## 📌 项目简介
使用多种分类模型预测 Titanic 乘客的幸存情况，重点进行了**特征工程**（包括舱位-性别交互特征、年龄分桶-性别交互特征）和**误差分析**，并对比了不同模型的表现。

## 📁 数据集
- 训练集：`train.csv`（**891** 条乘客记录，含标签 `Survived`）
- 测试集：`test.csv`（**418** 条乘客记录，无标签，用于提交）

数据来源：[Kaggle Titanic 竞赛](https://www.kaggle.com/c/titanic)

## 🔧 特征工程
- 删除无用列：`PassengerId`, `Ticket`, `Cabin`, `Name`
- 缺失值处理：
  - `Age`：用训练集中位数（约 30 岁）填充（缺失 **177** 个）
  - `Embarked`：用众数 'S' 填充（缺失 **2** 个）
  - `Fare`：仅测试集可能缺失，用中位数填充
- 新特征：
  - `FamilySize = SibSp + Parch + 1`
  - `Pclass_Sex`：舱位与性别的交互特征（例如 `1_0` 表示一等舱男性）
  - `AgeBucket`：年龄分桶（Child ≤12, Adult ≤60, Senior >60）
  - `AgeSex`：年龄分桶与性别的交互特征
- 编码：
  - `Sex`：`male` → 0, `female` → 1
  - 分类特征 `Embarked`, `Pclass_Sex`, `AgeSex` 使用 One-Hot 编码

## 🤖 模型与交叉验证
使用 `StratifiedKFold`（**5 折**）评估以下模型：

| 模型 | 平均准确率 | 标准差 |
|------|-----------|--------|
| **Logistic Regression** | **83.39%** | ±1.34% |
| KNN | 74.07% | ±1.03% |
| Decision Tree | 77.66% | ±3.51% |
| Random Forest | 80.81% | ±1.32% |

**有趣发现**：逻辑回归在此次特征工程下表现优于随机森林，可能是因为交互特征已经足够表达非线性关系，而随机森林可能需要更多调优。

## 📊 误差分析（核心亮点）
选择表现最好的**逻辑回归**模型进行误差分析（也可选随机森林，但此处以逻辑回归为例）。将训练集拆分为 80% 训练子集、20% 验证子集（保持类别比例），分析验证集上的错误样本。

**验证集统计**（来自逻辑回归）：
- 验证集总数：**179**
- 错误样本数：**31**
- 错误率：**17.32%**（准确率 82.68%）

**错误样本特征分析**：
- 性别分布：男性错误 **22** 个，女性错误 **9** 个 → 男性预测准确率相对较低
- 舱位等级分布：三等舱错误 **16** 个，一等舱 **12** 个，二等舱 **3** 个 → 一等舱错误率较高（约 25.6%）
- 错误样本平均年龄 **29.90** 岁，正确样本平均年龄 **28.78** 岁 → 年龄差异不显著

**改进效果**：
- 基础模型（无交互特征）错误率约 19.55%
- 添加 `Pclass_Sex` 交互特征后，错误率降至 17.88%
- 进一步添加 `AgeSex` 交互特征后，错误率降至 **17.32%**

## 🚀 最终提交
- 使用全部训练数据（891 条）重新训练**逻辑回归**模型（也可以选择随机森林，但根据交叉验证结果选择逻辑回归）
- 对测试集做相同的特征工程和缺失值填充
- 预测结果保存为 `submission.csv`，共 **418** 行（PassengerId 从 892 到 1309）
